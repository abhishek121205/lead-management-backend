## 🚀 Setup & Run Instructions

### 1. Install Dependencies
Open your terminal and run:
```bash
cd backend
npm install
```

### 2. Environment Variables
The `.env` file is already included and pre-configured with the live PostgreSQL (Neon) database and all necessary secrets. You do not need to change anything.

### 3. Start the Backend Server
```bash
npm run dev
```

The backend server will start at:
👉 **`http://localhost:5000`**
